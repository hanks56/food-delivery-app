# food-delivery-app

Bienvenido al proyecto APIfood, este es un proyecto educativo como estudiante de ADSO Sena. Lo estare realizando como proyecto de grado.
Para tener un poco el contexto de este proyecto, este proyecto esta enfocado para las personas que quieren y desean pedir comida a domicilio, en lo mas posible llevando un ahorro de tiempo y de prepara alimentos.
